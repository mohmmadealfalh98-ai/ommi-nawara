حلويات أمي نوارة — ملفات الموقع
================================

المحتويات:
- index.html: الموقع كامل (HTML + CSS + JavaScript).

طريقة المعاينة:
1. فك ضغط الملف.
2. افتح index.html في متصفح حديث.
3. الصور مرتبطة بروابط الصور التي أرسلتموها، لذلك يلزم اتصال بالإنترنت حتى تظهر.

طريقة النشر المجاني على Netlify:
1. افتح https://app.netlify.com/drop
2. اسحب مجلد الموقع بعد فك الضغط إلى الصفحة.
3. انتظر اكتمال النشر وسيظهر رابط الموقع.
